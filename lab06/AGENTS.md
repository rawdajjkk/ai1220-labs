# Lab 06 project rules
REQUIREMENTS.md is the authoritative source of acceptance criteria. Keep REQUIREMENTS.md and fees.py unchanged.
Use only the Python standard library. Tests use unittest, live in tests/, and import with `from fees import late_fee`.
Run tests from lab06 with `python3 -m unittest discover -s tests`.
The tester reads requirements and writes tests only; it must not read fees.py or run tests.
The reviewer reads requirements and fees.py only; it must not read tests or change any file.
Keep the active permission profile. Do not request or accept commands outside the sandbox. Do not use the network.
Record observed results honestly; never mark an unrun sandbox check PASS.
