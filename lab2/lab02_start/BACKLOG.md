# Backlog — LabLoans

LabLoans is a system that helps the lab keep track of borrowed equipment and make sure it is returned.

## Items

- [F] Lab staff need to record which equipment has been borrowed and who borrowed it.
- [F] Lab staff need to see which equipment is currently available or on loan.
- [F] Borrowers need to know when their borrowed equipment is due for return.
- [F] Lab staff need to identify equipment that has not been returned on time.
- [F] Borrowers need to confirm when equipment has been returned.
- [NF] Borrower information must only be accessible to authorized lab staff.
- [NF] The system should show updated equipment availability quickly after a loan or return is recorded.
- [NF] The system should be simple enough for lab staff to use without special training.
